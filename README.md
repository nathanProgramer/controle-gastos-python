# Controle de Gastos Pessoais

Aplicação desenvolvida em Python para controle de gastos pessoais,
utilizando a regra 50/30/20 como base para organização financeira.

## Funcionalidades

- Cadastro de salário
- Cadastro de gastos
- Organização dos gastos por categorias
- Controle de gastos parcelados
- Listagem dos gastos cadastrados
- Resumo financeiro baseado na regra 50/30/20
- Salvamento dos dados em arquivo JSON
- Tratamento de erros de entrada

## Tecnologias utilizadas

- Python
- JSON
- Git
- GitHub

## Como executar

1. Tenha o Python instalado.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no VS Code.
4. Execute o arquivo:

```bash
python controle_gastos.py
